* Persistent Sorted Set → Rust/WASM with AbsurderSQL Storage

** Overview

Port the JS persistent sorted set (B+ tree) to Rust, compiled to WASM via =wasm-pack=.
Use =absurder-sql= (Rust) as the underlying SQLite storage, so node store/restore
never crosses the JS↔WASM boundary.

** Architecture

#+begin_example
┌─────────────────────────────┐
│  ClojureScript (DataScript)  │
│  persistent_sorted_set.cljs  │  ← thin wrapper (same API)
└──────────┬──────────────────┘
           │ wasm-bindgen (conj/disj/slice/store/restore)
┌──────────▼──────────────────┐
│  Rust WASM module            │
│  ┌─────────────────────────┐│
│  │ persistent-sorted-set   ││  ← B-tree logic (pure Rust)
│  │   uses ↓                ││
│  │ SQLiteStorage (IStorage)││  ← stores nodes as SQLite rows
│  │   uses ↓                ││
│  │ absurder-sql            ││  ← SQLite + IndexedDB VFS
│  └─────────────────────────┘│
│  (single .wasm binary)      │
└─────────────────────────────┘
#+end_example

The critical win: *node restore/store never leaves WASM*. Only =conj=/=disj=/=slice=
results cross the boundary, and those are individual datom values that already had to
cross anyway.

** Design decisions

- *Values are =JsValue=*: The set stores arbitrary JS values (datoms). The comparator
  is a JS function called via =wasm-bindgen=. Datoms remain as =JsValue= on the WASM
  boundary.
- *Node = Rust enum*: =enum Node { Leaf(Leaf), Branch(Branch) }= replaces the OOP
  hierarchy. Pattern matching replaces =instanceof=.
- *=Rc<Node>= for structural sharing*: Persistent trees share subtrees. Use =Rc<Node>=
  (single-threaded WASM) instead of WeakRef/cloning.
- *Sentinel returns replaced by enums*: =UNCHANGED=/=EARLY_EXIT= arrays become
  =AddResult= / =RemoveResult= enum variants.
- *Addresses are =i64=*: SQLite rowids, not =JsValue=. Eliminates serialization
  overhead for the storage layer.

*** Store (called bottom-up during =set.store()=)

#+begin_src rust
fn store(&mut self, node: &Node) -> i64 {
    let addr = self.next_addr();
    match node {
        Node::Leaf(leaf) => {
            let keys_blob = serialize_keys(&leaf.keys);
            self.db.execute(
                "INSERT INTO pss_nodes (addr, level, keys) VALUES (?, 0, ?)",
                &[addr, keys_blob]
            );
        }
        Node::Branch(branch) => {
            let keys_blob = serialize_keys(&branch.keys);
            let addrs_blob = serialize_addrs(&branch.addresses);
            self.db.execute(
                "INSERT INTO pss_nodes (addr, level, keys, addrs) VALUES (?, ?, ?, ?)",
                &[addr, branch.level, keys_blob, addrs_blob]
            );
        }
    }
    addr
}
#+end_src

*** Restore (called lazily when tree walks into a stored subtree)

#+begin_src rust
fn restore(&self, address: i64) -> Node {
    if let Some(cached) = self.cache.get(&address) {
        return cached.clone();
    }
    let row = self.db.query_row(
        "SELECT level, keys, addrs FROM pss_nodes WHERE addr = ?",
        &[address]
    );
    let keys = deserialize_keys(row.keys_blob);
    if row.level == 0 {
        Node::Leaf(Leaf { keys, .. })
    } else {
        let addresses = deserialize_addrs(row.addrs_blob);
        Node::Branch(Branch { level: row.level, keys, addresses, children: None, .. })
    }
}
#+end_src

*** Datom serialization strategy

Datoms are CLJS objects =[e a v tx]=. Use a compact binary encoding (not EDN):
- Entity ID (=e=): i64
- Attribute (=a=): string (interned/indexed)
- Value (=v=): tagged union (type byte + payload)
- Transaction (=tx=): i64

This is faster than the current EDN round-trip through JS.

** Storage lifecycle integration

*** Current flow (JS)

1. =store-impl!= → walks tree, serializes datoms as EDN, stores via =IStorage= protocol (JS↔CLJS)
2. =restore-impl= → reads root metadata, lazily loads tree from =IStorage= (JS↔CLJS)

*** New flow (Rust)

1. *Store*: Rust =PersistentSortedSet::store()= writes nodes directly to SQLite.
   CLJS only stores metadata (schema, max-eid, max-tx, root addresses) — one small write.
2. *Restore*: CLJS calls =PersistentSortedSet::restore_from_storage(address, db_handle)=
   which constructs a lazy tree rooted at the given address. Node loading happens in Rust.
3. *Garbage collection*: =walk_addresses= stays the same.
   =collect_garbage= deletes unused rows: =DELETE FROM pss_nodes WHERE addr NOT IN (...)=.

** CLJS wrapper changes

=persistent_sorted_set.cljs= needs minimal changes:
- Swap the import from =persistent_sorted_set_js/index.min= to the wasm-pack output
- The =extend-type= protocol implementations remain the same
- =StorageAdapter= in =storage.cljs= is simplified — no longer serializes/deserializes
  datoms in CLJS; the Rust side handles it

** Risks and mitigations

| Risk                              | Mitigation                                                                                                                                                          |
|-----------------------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Datom serialization cost          | Binary format (not EDN). Benchmark vs current JS→string→JS path — likely faster.                                                                                   |
| Comparator crosses WASM boundary  | Unavoidable for custom CLJS comparators. But =contains=/=search= during restore can use a Rust comparator if datoms are in a known binary format.                   |
| absurder-sql async API            | Use =sqlite-wasm-rs= directly (synchronous =rusqlite::Connection=) inside the same WASM module, bypassing the async layer.                                         |
| Single .wasm binary size          | absurder-sql + SQLite + B-tree. Use =wasm-opt -Oz=. Should be manageable (~500KB–1MB gzipped).                                                                     |
| WASM module init is async         | Load once at app startup. DataScript operations are synchronous after init.                                                                                         |

** What NOT to port

- =Registry.js= — debug only
- =hashCode=/=equals= — keep in CLJS protocol extensions
- =map=/=filter=/=forEach=/=reduce= — keep in CLJS, just iterate over Seq
- =RefType.SOFT= — irrelevant in WASM; use =Rc= for structural sharing
- The entire JS =IStorage= → CLJS =StorageAdapter= bridge — *replaced by =SQLiteStorage= in Rust*

pub struct Leaf {
    pub(crate) keys: Vec<JsValue>,
    pub(crate) settings: Settings,
}

impl Leaf {
    pub fn new(settings: Settings) -> Self;
    pub fn with_keys(keys: Vec<JsValue>, settings: Settings) -> Self;

    /// Add key. Paths:
    ///   1. Key exists → Unchanged
    ///   2. Fits + editable → insert in-place, EarlyExit
    ///   3. Fits + immutable → new Leaf, One(node)
    ///   4. Full → Split(left, right).  Split: half1 = (len+1)/2
    pub fn add(&self, key: JsValue, cmp: &Comparator, settings: &Settings) -> AddResult;

    /// Remove key. Paths:
    ///   1. Not found → Unchanged
    ///   2. No rebalance needed + editable → EarlyExit
    ///   3. No rebalance needed + immutable → Rebalanced{left, new, right}
    ///   4. Join-left → Rebalanced{None, merged, right}
    ///   5. Join-right → Rebalanced{left, merged, None}
    ///   6. Borrow-left → Rebalanced{new_left, new_center, right}
    ///   7. Borrow-right → Rebalanced{left, new_center, new_right}
    pub fn remove(&self, key: &JsValue,
                  left: Option<&Leaf>, right: Option<&Leaf>,
                  cmp: &Comparator, settings: &Settings) -> RemoveResult;

    pub fn contains(&self, key: &JsValue, cmp: &Comparator) -> bool;
    pub fn count(&self) -> usize;
    pub fn store(&self, storage: &mut dyn IStorage) -> i64;
}

*** =src/branch.rs= — Branch node (level >= 1)

#+begin_src rust
pub struct Branch {
    pub(crate) level: u32,
    pub(crate) keys: Vec<JsValue>,                    // keys[i] = max_key of children[i]
    pub(crate) addresses: Option<Vec<Option<i64>>>,    // SQLite rowids, nullable per-slot
    pub(crate) children: Option<Vec<Option<Rc<Node>>>>,
    pub(crate) settings: Settings,
}

impl Branch {
    /// Get child at index, lazily loading from storage if needed.
    pub fn child(&self, storage: &dyn IStorage, idx: usize) -> Rc<Node>;

    /// Set child at index, clearing its address (marks as dirty).
    pub fn set_child(&mut self, idx: usize, child: Rc<Node>);

    /// Add key. After recursive descent into child:
    ///   1. Child Unchanged → Unchanged
    ///   2. Child EarlyExit → EarlyExit
    ///   3. Child One(node), editable → update in place
    ///   4. Child One(node), immutable → new Branch
    ///   5. Child Split(l,r), fits → new Branch with extra child
    ///   6. Child Split(l,r), full → split this Branch too
    ///      Split adjustment: if ins+1 == half1 then half1++
    pub fn add(&self, storage: &dyn IStorage, key: JsValue,
               cmp: &Comparator, settings: &Settings) -> AddResult;

    /// Remove key. new_len calculation:
    ///   new_len = self.len - 1
    ///             - left_child.is_some() - right_child.is_some()
    ///             + result_left.is_some() + 1 + result_right.is_some()
    pub fn remove(&self, storage: &dyn IStorage, key: &JsValue,
                  left: Option<&Branch>, right: Option<&Branch>,
                  cmp: &Comparator, settings: &Settings) -> RemoveResult;

    /// Store bottom-up: store unstored children first, then self.
    pub fn store(&self, storage: &mut dyn IStorage) -> i64;

    pub fn walk_addresses(&self, storage: &dyn IStorage, on_address: &mut dyn FnMut(i64) -> bool);
}

/// Sorted set iterator — forward or reverse, with optional bounds
pub struct Seq {
    set: *const PersistentSortedSet,  // back-reference for storage + version
    leaf: Rc<Node>,                   // current Leaf node
    idx: usize,                       // index within leaf
    stack: Option<Box<SeqFrame>>,     // parent stack (branch frames)
    key_to: Option<JsValue>,          // upper/lower bound (inclusive)
    cmp: Option<Comparator>,
    ascending: bool,
    version: u64,
}

impl Seq {
    pub fn first(&self) -> &JsValue;
    pub fn over(&self) -> bool;  // ascending: current > bound; descending: current < bound
    pub fn advance(&mut self) -> bool;  // move to next; pop stack + descend when leaf exhausted
    pub fn next(&self) -> Option<Seq>;  // clone + advance
    pub fn seek(&self, to: &JsValue, cmp: Option<&Comparator>) -> Option<Seq>;
    pub fn to_array(&self) -> Vec<JsValue>;
    fn check_version(&self);  // panic if set mutated since creation
}
#+end_src

Stack navigation (ascending, leaf exhausted):
1. =self.idx >= self.leaf.len() - 1= → done with this leaf
2. Pop stack: =frame = self.stack.take()=
3. Advance frame: =frame.idx += 1=
4. If =frame.idx < frame.node.len()=: push back, descend to =child(frame.idx)=, reset =idx=0=
5. Else: recurse up (pop next frame)

fn js_to_comparator(f: js_sys::Function) -> Comparator {
    Box::new(move |a: &JsValue, b: &JsValue| {
        let result = f.call2(&JsValue::NULL, a, b)
            .unwrap()
            .as_f64()
            .unwrap_or(0.0);
        if result < 0.0 { Ordering::Less }
        else if result > 0.0 { Ordering::Greater }
        else { Ordering::Equal }
    })
}
